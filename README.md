# Task Management OS

A personal Task Management OS — an offline-first, mobile-first productivity app combining gamification, AI-powered task scoring, and a command palette.

## 🎯 Overview

This project is my personal operating system for life: a PWA that works offline, syncs with Supabase, and provides advanced productivity features.

## ✨ Key Features

- Offline-first PWA with Service Workers
- Mobile-first navigation and UX
- AI-powered daily picks scoring algorithm
- Command palette (⌘K) with natural language commands
- CSV export/import for tasks
- Gamification: XP, badges, quests
- North Star Pace Engine for metric tracking & forecasting

## 🛠️ Tech Stack

- Frontend: Vanilla JS, HTML, CSS (PWA)
- Backend / Sync: Supabase
- Hosting: Vercel
- Optional: Node scripts for build and export

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (for local dev scripts)
- npm or yarn

### Local install

1. Clone the repo
```bash
git clone https://github.com/panoskokmotos/task-management.git
cd task-management
```

2. Install dependencies (if applicable)
```bash
npm ci
```

3. Run tests (if any)
```bash
npm test || echo "No tests configured"
```

4. Build (if applicable)
```bash
npm run build || echo "No build step"
```

### Quick deploy
- Deploy to Vercel or any static host. The live demo is: https://task-management-beige-eight.vercel.app
